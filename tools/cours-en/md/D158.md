## 📘 1. Grammatik (45 min) — Struktur einer guten Erklärung

1. **Kurzdefinition**: *Kurz gesagt ist ein Pointer eine Variable, die eine Speicheradresse enthält.*  
2. **Vergleich/Analogie**: *Man kann es sich wie eine Hausadresse vorstellen: …*  
3. **Funktionsweise** (Passiv + Reihenfolge): *Zuerst wird Speicher reserviert, dann wird die Adresse gespeichert…*  
4. **Beispiel**  
5. **Verständnis prüfen**: *Ist das soweit verständlich? · Gibt es Fragen?*  
**Code vorlesen**: `x = 5` „x wird 5 zugewiesen" · `==` „ist gleich" · `!=` „ungleich" · `i++` „i wird um eins erhöht" · `arr[i]` „arr an Index i" · `()` runde Klammern · `[]` eckige Klammern · `{}` geschweifte Klammern · `;` Semikolon · `_` Unterstrich · `/` Schrägstrich · `\` Backslash · `#` Raute · `|` senkrechter Strich / Pipe

## 📗 2. Wortschatz (40 min) — IT-Fachwortschatz (B2)

| Wort / Ausdruck | Meaning | Beispiel |
|---|---|---|
| **der Speicher / der Arbeitsspeicher** | memory / RAM | *Der Speicher wird freigegeben.* |
| **die Variable, -n** | the variable | *Die Variable enthält einen Wert.* |
| **die Funktion, -en / aufrufen** | the function / to call | *Die Funktion wird rekursiv aufgerufen.* |
| **der Rückgabewert** | the return value | *Der Rückgabewert ist NULL.* |
| **die Schleife, -n** | the loop | *Eine Endlosschleife!* |
| **die Bedingung, -en** | the condition | *Wenn die Bedingung erfüllt ist…* |
| **der Zeiger / der Pointer** | the pointer | *Ein Zeiger zeigt auf eine Adresse.* |
| **die Datenstruktur, -en** | the data structure | *Eine verkettete Liste ist eine Datenstruktur.* |
| **kompilieren / ausführen** | to compile / to run | *Das Programm wird kompiliert und ausgeführt.* |
| **der Grenzfall, ¨-e** | the edge case | *Hast du die Grenzfälle getestet?* |
| **die Schnittstelle, -n** | the interface (API) | *Die Schnittstelle ist gut dokumentiert.* |

**Method:** read each example out loud twice. For nouns, **always learn the article and the plural** (tip: one colour per gender in Anki — 🔵 der, 🔴 die, 🟢 das). Anki card: *front* = example sentence with `____`, *back* = the word. Then write **your own sentence** with 8 of these words.

## 📖 3. Lesen (30 min) — Rekursion erklärt

> Kurz gesagt ist Rekursion, wenn eine Funktion sich selbst aufruft. Man kann es sich wie russische Puppen vorstellen: Um die kleinste Puppe zu finden, öffnet man eine Puppe nach der anderen, bis man eine findet, die sich nicht mehr öffnen lässt. Diese letzte Puppe nennt man den Basisfall.  
> Im Code funktioniert das genauso: Bei jedem Aufruf wird ein kleineres Teilproblem gelöst. Sobald der Basisfall erreicht ist, ruft sich die Funktion nicht mehr auf, und die Ergebnisse werden nacheinander zurückgegeben.  
> Der häufigste Fehler? Den Basisfall zu vergessen – dann läuft die Funktion endlos weiter, bis es zu einem Stack Overflow kommt. Ist das soweit verständlich?

Finde die 5 Teile einer guten Erklärung und alle Passivformen.

Zwei Tage bis zum Gespräch. Katrin hat erfahren, dass die Fallstudie vielleicht eine technische Komponente hat. „Du musst technische Dinge auf Deutsch erklären können. Für Nicht-Techniker.“

Malik lernt heute die technischen Wörter auf Deutsch: *der **Speicher**, die **Variable**, die **Funktion** (eine Funktion **aufrufen**), der **Rückgabewert**, die **Schleife**, die **Bedingung**, der **Zeiger**, die **Datenstruktur**, **kompilieren** und **ausführen**, der **Grenzfall**, die **Schnittstelle**, die **Versionsverwaltung**.*

Er übt mit Elif, die gerade in der Piscine mit Zeigern kämpft. Er **betreut** sie eine Stunde lang. Er will sie **unterstützen**, ohne ihr die Lösung zu geben.

„Ich verstehe **Zeiger** einfach nicht“, sagt Elif. „Alle sagen, es ist einfach. Aber es ist nicht einfach!“

„Okay. Stell dir vor, der **Speicher** ist eine lange Straße mit Häusern. Jedes Haus hat eine Adresse. In jedem Haus wohnt ein Wert — eine Zahl, ein Buchstabe.“

„Okay…“

„Eine **Variable** ist ein Haus mit einem Namen. Zum Beispiel: Im Haus ‚alter‘ wohnt die Zahl siebzehn.“

„Verstanden.“

„Und ein **Zeiger** ist ein Zettel, auf dem die Adresse eines Hauses steht. Nicht der Wert selbst — nur die Adresse. Wenn du den Zettel hast, kannst du zum Haus gehen und nachsehen, wer dort wohnt.“

Elif denkt nach. „Ah! Also ist der Zeiger wie… Google Maps? Er zeigt mir, wo etwas ist?“

„Genau! Und wenn du eine **Funktion** **aufrufst** und ihr einen Zeiger gibst, kann die Funktion direkt in das Haus gehen und den Wert ändern.“

„Und wenn die Adresse falsch ist?“

„Das ist ein **Grenzfall**. Dann stürzt das Programm ab. Ein Segmentation Fault.“

„Den hatte ich heute zehnmal!“, lacht Elif.

„Willkommen in der Piscine.“

Nach einer Stunde **kompiliert** Elif ihr Programm und **führt** es **aus**. Es funktioniert. Sie **springt** auf und umarmt Malik.

„Danke! Du erklärst besser als alle Videos!“

„Weil ich es auf Deutsch erklärt habe. Mit Häusern. Das ist mein Berliner Stil.“

Am Abend übt er mit Katrin die Erklärung für eine Nicht-Technikerin. Katrin spielt Frau Dr. Brandt.

„Herr Benali, erklären Sie mir bitte, was eine **Schnittstelle** ist.“

„Eine Schnittstelle ist wie eine Steckdose. Man muss nicht wissen, wie der Strom produziert wird. Man muss nur wissen, wie man den Stecker einsteckt. In der Software ist die Schnittstelle die Steckdose zwischen zwei Programmen.“

„Und warum ist das für Pädagogik relevant?“

„Weil gute Pädagogik auch Schnittstellen braucht: zwischen den Studierenden und den Mentoren, zwischen den Standorten, zwischen der Schule und den Unternehmen. Meine Aufgabe als Leitung wäre, diese Schnittstellen zu bauen und zu **fördern**.“

Katrin lacht. „Du hast eine Steckdose in eine Bewerbungsantwort verwandelt.“

„Das ist mein Talent.“

Am Ende des Tages schreibt Malik eine kurze E-Mail an Frau Schneider, um seine Anreise zu bestätigen. Er endet mit: *Ich freue mich auf das Gespräch und **ich freue mich auf Ihre Rückmeldung** zu den Details des Ablaufs.*
