## 📘 1. Grammatik (45 min) — Anglicisms and how they fit in

Tech German borrows a lot from English, but **the verbs are conjugated the German way**:  
- *downloaden → ich downloade, ich habe **gedownloadet*** (or better: *herunterladen → heruntergeladen*)  
- *updaten → **upgedatet*** (oral) · *googeln → **gegoogelt*** · *chatten → **gechattet*** · *debuggen → **gedebuggt*** · *pushen → **gepusht*** · *committen → **committet***  
- Gender of anglicisms: often that of the equivalent German word: *die App* (die Anwendung), *die E-Mail* (die Post), *der Computer* (der Rechner), *das Update*, *der Bug* (der Fehler), *das Feature*, *das Repository* / *das Repo*  
- Germans also use 100% German words: *die Datei* (file), *der Ordner* (folder), *speichern* (save), *löschen* (delete), *der Rechner* (computer), *die Festplatte* (hard drive), *der Arbeitsspeicher* (RAM), *das Netzwerk* (network), *der Datenschutz* (data protection)

**Übung A — Past participle.** 1. Ich habe die Datei ___ (speichern). 2. Hast du das schon ___ (googeln)? 3. Wir haben den Bug ___ (fixen). 4. Ich habe die App ___ (herunterladen). 5. Er hat seinen Code ___ (pushen). 6. Ich habe den Ordner ___ (löschen).

## 📗 2. Wortschatz (40 min) — IT-Wortschatz

| Wort / Ausdruck | Meaning | Beispiel |
|---|---|---|
| **der Rechner, - / der Computer, -** | the computer | *Mein Rechner ist langsam.* |
| **die Datei, -en** | the file | *Die Datei ist zu groß.* |
| **der Ordner, -** | the folder | *Speichere es im Ordner „Projekte".* |
| **speichern** | to save | *Hast du gespeichert?* |
| **löschen** | to delete | *Lösch die alte Version.* |
| **herunterladen / hochladen** | to download / to upload | *Lade die Datei hoch.* |
| **der Fehler, - / der Bug, -s** | the error / the bug | *Ich suche den Fehler.* |
| **die Anwendung, -en / die App, -s** | the application | *Die App stürzt ständig ab.* |
| **abstürzen (ist abgestürzt)** | to crash | *Der Server ist abgestürzt.* |
| **das Passwort, ¨-er** | the password | *Ändere dein Passwort.* |
| **der Datenschutz** | data protection | *Datenschutz ist in Deutschland sehr wichtig.* |
| **die Leistung** | performance | *Die Leistung ist besser geworden.* |
| **der Arbeitsspeicher / die Festplatte** | RAM / the hard drive | *Ich brauche mehr Arbeitsspeicher.* |
| **das Netzwerk, -e** | the network | *Das Netzwerk ist langsam.* |

**Method:** read each example out loud twice. For nouns, **always learn the article and the plural** (tip: one colour per gender in Anki — 🔵 der, 🔴 die, 🟢 das). Anki card: *front* = example sentence with `____`, *back* = the word. Then write **your own sentence** with 8 of these words.

## 📖 3. Lesen (30 min) — Ein Bug-Report

> **Titel:** App stürzt beim Hochladen von Bildern ab  
> **Beschreibung:** Wenn man ein Bild hochlädt, das größer als 10 MB ist, stürzt die App ab. Der Fehler tritt nur auf Android auf. Ich habe es auf zwei Geräten getestet.  
> **Schritte:** 1. App öffnen 2. Auf „Bild hochladen" klicken 3. Eine große Datei auswählen  
> **Erwartet:** Das Bild wird hochgeladen oder es erscheint eine Fehlermeldung.  
> **Tatsächlich:** Die App schließt sich ohne Meldung.

1. Wann stürzt die App ab? 2. Auf welchem System? 3. Was sollte passieren? 4. Was passiert wirklich?

Am Montag ist Emmas erster Arbeitstag. Am Sonntagabend will sie ihre Präsentation vorbereiten. Plötzlich: Der Laptop **ist abgestürzt**.

„Malik! Hilfe! Mein **Rechner** ist tot!“

Malik kommt sofort. Er **versteht** sofort das Problem. „Hast du die **Datei** **gespeichert**?“

„Ich glaube… nein. Vielleicht. Ich weiß nicht!“

„Okay. Keine Panik. Ich **erkläre** dir, was wir machen.“

Er startet den Laptop neu. Ein schwarzer Bildschirm. Dann ein Fehler: *Festplatte nicht gefunden*.

„Oh nein. Die **Festplatte**.“

„Ist alles weg?“

„Vielleicht nicht. Hast du die **Datei** in der Cloud? Hast du sie **hochgeladen**?“

„Ich weiß mein **Passwort** nicht mehr!“

Malik lernt heute die IT-Wörter auf Deutsch. Viele sind Anglizismen: der Computer, die App, der Bug, hochladen (upload), herunterladen (download). Aber es gibt auch deutsche Wörter: der **Rechner**, die **Datei**, der **Ordner**, **speichern**, **löschen**, **abstürzen**.

Sie suchen das **Passwort**. Emma hat es in einem Notizbuch geschrieben. Gefunden!

Malik **lädt** die Datei aus der Cloud **herunter**. Auf seinem Laptop. Da ist sie: *Praesentation_Final_v3.pptx*.

„Ich liebe dich“, sagt Emma.

„Ich weiß“, lacht Malik.

Dann klingelt sein Handy. Es ist Jonas.

„Malik, der Welcomer-Server ist auch **abgestürzt**! Die **Anwendung** funktioniert nicht!“

„Jetzt? Sonntagabend? **Ich rufe später an**, okay? Ich habe gerade einen anderen Notfall.“

Um zehn Uhr ruft er zurück. Der **Arbeitsspeicher** des Servers ist voll, und das **Netzwerk** ist zu langsam. Zu viele Nutzer. Eine gute Nachricht und eine schlechte Nachricht.

„Wir müssen den **Datenschutz** prüfen“, sagt Jonas. „Und die **Leistung** verbessern. Kannst du das morgen machen?“

„Morgen ist Emmas erster Tag. Und ich habe eine Besprechung. Am Dienstag. Ich **wiederhole**: Dienstag.“

„Okay, okay.“

Um Mitternacht liegen beide im Bett. Emma sagt: „Danke für heute. Du bist mein IT-Held.“

„Und du bist meine erste Nutzerin. Und meine wichtigste.“

*Hilfe: der Absturz = the crash · vorbereiten = to prepare · tot = dead · startet neu = restarts · der Bildschirm = the screen · weg = gone · lädt … herunter = downloads · der Notfall = the emergency · ruft zurück = calls back · die Nutzer = the users · prüfen = to check · verbessern = to improve · der Held = the hero*
